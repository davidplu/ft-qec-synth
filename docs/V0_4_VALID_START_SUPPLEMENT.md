# Supplemental valid-start construction

The originally prespecified duplicate-full-interval affine start failed target
certification before its compression comparison. It remains in calibration
evidence and is never replaced in the primary experiment.

For a separate generic compression demonstration, prepare every prefix flag
(0,p), p=1..weight, once per check, independent syndrome slots, serialized
checks, one extra noisy terminal round. This prescription is independent of
measured resource savings and applies to Steane7, affine15_k1, simplex15_k7,
X memory, seeds 10,11,12. Permute data interaction orders with each seed; do
not import an expert circuit or select an order for favorable compression.

Screen with the native target=3, cap=200000 evaluator. Ineligible starts are
reported. Eligible starts get 48 matched repair_only/repair_compress slots,
same frozen source and settings. Independently audit all final Pareto circuits.
This is supplemental evidence, not a replacement for the predeclared readiness
coverage requirement or a license to change its thresholds. No resource
outcomes from this construction have been seen when writing this protocol.
