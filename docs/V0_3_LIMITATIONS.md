# V0.3 scope and limitations

Malignant counts are exact only for completely enumerated layers. Higher or capped
layers are unknown, including when a minimum witness was found before a full count
could finish. Count improvements never certify circuit distance.

The ideal encoded input, local gate Pauli model, physical product logical readout,
chosen logical index and optional-idle semantics remain the V0.2 model. An added
terminal verification round is fully noisy and increases resources. Pure terminal
readout faults and incompatible non-CSS boundaries can remain irreparable.

The equivalence relation is conservative and architecture-dependent. Key turnover
can reflect a changed mechanism descriptor; it is not by itself proof that a
parent realization was physically eliminated. The report separates raw count,
class count, exact source transport, whole-parent-class transport, new keys and
net count changes. Signature classes can be too coarse to preserve neutral gains.

The beam has a fixed cap and a small expiring protection quota. Intermediate gains
can still be lost, and estimated repair coverage is not an exhaustive assessment
of all operator possibilities. Within-run failure/operator memory does not carry
learned outcomes between seeds or experimental variants.

Gradient probabilities are observed descendants in a finite, adaptively selected
search tree. Unselected candidates have censored futures. Different exposure,
shared ancestry and shared code inputs prevent a causal interpretation. Paired
endpoint tests are conditional development evidence, not an independent external
benchmark or proof of generality. A long ancestry is not proof that every repair
was necessary. Gains beyond a weak parent are distinct from beating the best
shared initial architecture.

No exact local incremental update is assumed after schedule, flag, reset or record
changes. Full-circuit signatures and classes are cached for exact duplicates.
Large-code throughput, stochastic logical-error rates, hardware routing and global
optimality remain untested. Only protocol development codes are run. No held-out
architecture, code input or optimized circuit is accessed.
