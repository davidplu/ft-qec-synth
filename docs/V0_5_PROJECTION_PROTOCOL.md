# Prospective generic logical-projection certificate supplement

Higher-distance type/SAT/physical-pair experiments expose both capped proofs and
real low-distance architecture failures. Add a bounded structural certificate
which makes no assumption about ideal cat correctness or flag fault tolerance.
This is an exact alternative lower-bound method, not a new extraction family.

From the raw stabilizer-compatible physical product readout, enumerate at most
4096 representatives of the selected logical operator modulo compatible
stabilizer products. Greedily select disjoint supports, sorted by weight then
mask. Derive coordinate error flips from these **already measured data records**;
do not add physical operations or scientific detectors. Check that each
coordinate XOR the selected logical bit is a linear combination of the actual
detectors. Enumerate every legal physical fault variant and bound how many
coordinates a single fault can flip. If there are m coordinates and each
physical fault flips at most a, undetected logical failure requires at least
ceil(m/a) faults by Hamming-weight subadditivity. This bound applies to every
legal multi-fault set, not merely enumerated small subsets.

Generate relations using native suffix propagation. Independently verify
inventory/circuit hashes, every relation and every singleton coordinate weight
using the structurally separate forward Boolean physical interpreter. Save
coordinate masks and detector-combination coefficients as checkable payloads.
Physically replay terminal upper witnesses. Matrix/packing truncation affects
bound strength, never soundness. No extra logical measurement is treated as a
detector or as an ideal boundary check.

Fixed development ladder: Shor 5x5 and 7x7 raw code definitions, existing bare
interval-flag and verified-cat families, rounds 1 and 3, X and Z selected
observable. All configurations are run; do not keep only successful channels.
The full quantum parent codes have known distances five/seven, but this
certificate is for the **selected observable**, matching the existing FTQEC
memory model. It does not establish both-channel circuit fault tolerance.
The construction is standard; no new code family is claimed.

The method may exploit many disjoint logical representatives. A favorable large
Shor example does not establish useful certification for a denser 23-qubit code
with fewer disjoint representatives. Readiness still requires practical
generic higher-distance certification and the other original gates. Do not run
or inspect any held-out raw stabilizer/architecture as part of this supplement.
